# Sannidhhi Chemical Industries — Website

Next.js 15 (App Router), Tailwind CSS v4, Framer Motion. **Static export** output in `out/` after `npm run build`.

## Commands

- `npm run dev` — local development
- `npm run build` / `npm run export` — production static site → `out/`
- `npm run lint` — ESLint

Set `NEXT_PUBLIC_SITE_URL` to your production origin (e.g. `https://yourdomain.com`) for canonical URLs, Open Graph, and structured data.

Replace `public/assets/sannidhhi-product-catalog.pdf` with your real catalog when ready. The contact form is UI-only (no backend); use email, phone, or WhatsApp for live leads.
